# ✿ My Planner

A minha app *aesthetic* de gestão do dia a dia — tons creme, sálvia e terracota, tipografia elegante e modo escuro.

## Secções

- **Hoje** — saudação, frase do dia, tarefas de hoje (e as que ficaram para trás), rituais, resumo financeiro do mês e humor.
- **Planner** — vista semanal, tarefas por dia com etiquetas (Pessoal, Trabalho, Casa, Saúde, Estudo) e "Foco da semana".
- **Hábitos** — grelha dos últimos 7 dias com séries 🔥.
- **Finanças** — receitas, despesas e saldo por mês, gráfico por categoria, orçamentos com barras de progresso e lista de movimentos.
- **Diário** — humor do dia, 3 gratidões, escrita livre e calendário de humor do mês.
- **Metas** — intenção do mês e metas com prazo e progresso.
- **Definições** — nome, tema (auto/claro/escuro), moeda, exportar/importar cópia de segurança.

## Como usar

Não precisa de instalação nem de build — é HTML, CSS e JavaScript puro.

```bash
python3 -m http.server 8080
# abrir http://localhost:8080
```

Para a ter no telemóvel como app, publica a pasta (ex.: GitHub Pages, Netlify ou Vercel), abre o link no telemóvel e escolhe **"Adicionar ao ecrã principal"**. Funciona offline.

## Os teus dados

Tudo é guardado **apenas no teu dispositivo** (localStorage). Usa *Definições → Exportar cópia* para fazer backups ou passar os dados para outro dispositivo.
